# Практикум 2: коллекции и лямбды

Четыре функции. Четыре теста. Твоя задача — сделать так, чтобы все тесты стали зелёными.

**Сдано = зелёная галочка** у последнего пуша во вкладке Actions этого репозитория.

## С чего начать (если ты вообще не работал с Kotlin/Gradle)

1. **Установи JDK 21**, если его ещё нет. Например, [Eclipse Temurin](https://adoptium.net/) — просто скачай и поставь, как обычную программу. Kotlin компилируется в JVM, и Gradle без Java не запустится.
2. **Склонируй репозиторий** (кнопка "Use this template" уже создала тебе отдельную копию под твоим аккаунтом):
   ```
   git clone <ссылка на твой репозиторий>
   cd <имя-репозитория>
   ```
3. **Открой проект** в IntelliJ IDEA (Community — бесплатная) или в любом редакторе. IDEA сама подхватит Gradle-проект.

## Где решать

Открой `src/main/kotlin/Exercises.kt`. Там два готовых data class (`Person`, `Item`) — их трогать не нужно, — и четыре функции. У каждой функции в КДоке (комментарии над функцией) написано, что она должна делать, и приведены примеры вход → выход. Вместо `TODO("реализуй")` напиши код.

Все четыре функции решаются через стандартные операции над коллекциями (`filter`, `map`, `sum`, `groupBy`, `sortedDescending`, `take`) — без ручных циклов `for`. Это тот же стиль, в котором дальше в курсе будет строиться список экранов в UI Kit.

Тесты уже готовы и лежат в `src/test/kotlin/ExercisesTest.kt` — их менять не нужно.

## Как запустить тесты локально

Из корня проекта:

```
./gradlew test
```

(на Windows — `gradlew.bat test`)

Если видишь `4 tests completed, 4 failed` — это нормальное стартовое состояние шаблона, ты ещё не начал решать. После того как реализуешь все четыре функции, здесь должно быть `4 tests completed, 0 failed` и `BUILD SUCCESSFUL`.

Подробный отчёт по каждому тесту: открой `build/reports/tests/test/index.html` в браузере.

## Как сдавать

Просто закоммить изменения и запушь:

```
git add src/main/kotlin/Exercises.kt
git commit -m "решение"
git push
```

## Как понять результат в Actions

Открой вкладку **Actions** в своём репозитории на GitHub. После каждого пуша там появляется прогон с именем джобы **«Проверка»**:

- **Зелёная галочка** — все тесты прошли, задание засчитано.
- **Красный крестик** — хотя бы один тест упал. Нажми на прогон → на джобу «Проверка» → разверни шаг «Запуск тестов» и посмотри, какой тест упал и почему (тот же `kotlin.NotImplementedError`, что и локально, значит функция ещё не реализована; если ошибка другая — сравни фактический и ожидаемый результат в тексте ассерта).

**Важно:** сразу после создания репозитория из шаблона первый автоматический прогон в Actions будет красным (4 упавших теста) — это ожидаемо и правильно, ты ещё ничего не решал. Твоя задача — сделать его зелёным.
